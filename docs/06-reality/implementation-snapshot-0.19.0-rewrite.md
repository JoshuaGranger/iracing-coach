It has not been analysed natively, and the mapped store of phase 3 has not been tried on it (`acceptance/g1-native.md`, `acceptance/migration.md`).
- **Bot-driven G4.** The vJoy bot did not drive: it needs the control profile selected in iRacing's own `app.ini`, which the task could not write, and the bot code has moved to `iRacing-utility`. Every G4 window used the car parked in the pit stall, so engine branches that react to motion were not exercised on the rig (`acceptance/g4-performance.md`).
- **Garage cases not run:** a second car, saving under a new name (it writes into `Documents\iRacing\setups`), driving out of the stall, and the gate behaviour for a named commit (T7). The fixed collector was verified by replaying the live session's bytes, not by a second live session. A reload of the file already named, or a Revert, commits values only under the original rule; the `ae65a0a` build adds an exit-name rule for an unmodified exit, with tests and no rig garage session after it (`acceptance/g3-garage.md`, `collector/README.md`).
- **Autostart at sign-in.** The HKCU Run value is configured; no sign-in or reboot was done, so it is not exercised (`acceptance/collector-install.md`).
- **Starting the stack while the NAS is down.** The running stack tolerates an outage; starting during one needs a host automount, an owner question (Q1), so v1 does not claim NAS-independent start (`risks.md` R3). The off-host backup of `/srv/g-house/apps/iracing-coach` also stands as the first-release record left it (`acceptance/server-release.md`).
- **Memory with everything at once on the native stages:** the whole container with an upload overlapping an analysis, and a tuning job that loads two analyses, were not measured (`acceptance/g1-native.md`).
- **Garage61, Ask and any AI account** were not exercised (parked above).
- **Human use.** Joshua saw the v1 candidate before ruling to start the port (`owner-decisions-2026-10-02.md`), but no record holds a criticism list, and none shows him using the investigation, Live or Setups on his own data through the review link.
