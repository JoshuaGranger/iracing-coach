# Crate API (v1)

Public Rust types and signatures of the shared library crates. A workstream transcribes its crate's section into code; a consumer reads only this file. Anything not listed here is private to its crate. Source facts: `spikes/live-stack.md`, `spikes/ui-data.md`, `iracing-coach/skills/analyze-iracing-race/scripts/ibt_reader.py`, `companion-app/src/iRacingCoach.Coordinator/{IRacingSdkTelemetrySource,LiveTelemetry,LiveSteering,LiveTruthPolicy,RuntimeMapper}.cs` (deleted in wave 4; in Git history, last present at `3ff5e87`).

## 1. Crates, owners, dependencies

| Crate | Owner | Depends on | Used by |
|---|---|---|---|
| `coach_wire` | W0 (generated by `tools/wire/gen-wire.mjs` and `typify`) | serde, serde_json, regress (the pattern engine typify's generated code calls for `pattern` constraints) | every crate, collector, server |
| `coach_ibt` | W1 | coach_wire, serde (derive), sha2, thiserror | coach_live, collector, server |
| `coach_live` | W2 | coach_wire, coach_ibt, thiserror | collector, server (frame header only) |
| `coach_views` | W5 | coach_wire, serde, serde_json, sha2, thiserror | server |

Rules for all four crates:
- Errors are `thiserror` enums listed here; no `anyhow` in public signatures; no panic on any input bytes.
- "Missing" is `None` (or an empty `Vec` where stated), never zero. Readers return what the source holds: `VarTable` readers, `IbtFile::edge_scalar` and `Sample` keep a present non-finite float as its raw value (`Some(NaN)`, NaN array elements at their index), because the C# `??` fallbacks and Python's edge read select by presence, not finiteness. Outputs (`LiveState`, `TileText`, `RecordingSummary`, view files) never carry a non-finite number: there it is missing.
- Plain data types derive `Debug, Clone, PartialEq`; types written to golden files also derive `serde::Serialize` with `snake_case` field names exactly as listed. `coach_live` public types derive no serde traits; its tests read vectors through `serde` and `serde_json` dev-dependencies.
- No `unsafe` in `coach_ibt`, `coach_live`, `coach_views`. Memory-map access stays in the collector, which hands these crates byte slices.
- `coach_ibt`, `coach_live`, `coach_views` build and test on Windows and Linux.

Scaffold pins required by this file (step 0b adds them to `[workspace.dependencies]`): `serde` with the `derive` feature (`coach_ibt` derives `Serialize`). No other dependency is needed by these APIs. None of the four crates depends on `regex`: what they link reaches the collector, whose exe budget is 3 MB, and `regex` alone left it 31 KB under that budget (wave 1, W3). YAML and literal tokens use hand-written matchers; setup-key patterns use the subset matcher of 3.6. `regress` reaches the collector's dependency tree through `coach_wire` but not its exe: code is linked only where a generated wire type with a `pattern` is built or deserialized, which the collector never does (its 1.58 MB wave-1 release exe holds none of it). A collector change that starts using such a type is measured against the 3 MB budget by W3's acceptance build like any other.

### 3.2 Header and variable table

```rust
pub struct VarTable { /* private: Vec<VarHeader> + name index */ }

impl VarTable {
    /// IBT rules (ibt_reader.py:983-1023): unknown type code -> UnsupportedVarType; empty name,
    /// duplicate name -> Format; count <= 0 or row bounds exceeded -> Bounds. Text fields follow
    /// Python _decode_c_string (ibt_reader.py:275-281): bytes before the first NUL, UTF-8, else
    /// the same bytes as cp1252 with errors="replace" (0x81, 0x8D, 0x8F, 0x90, 0x9D -> U+FFFD).
    pub fn parse_ibt(var_bytes: &[u8], num_vars: i32, buf_len: i32) -> Result<VarTable, IbtError>;
    /// Live rules (C# :207-230): entries with unknown type, negative offset, count <= 0, empty name
    /// or row overflow are skipped, never an error. `map` is the whole map; reads var_header_offset.
    /// The table as a whole is Bounds when num_vars is outside 1..=16384, var_header_offset < 112,
    /// or the num_vars x 144 header bytes from var_header_offset run past the map.
    /// Name follows C# Encoding.ASCII over all 32 bytes (each byte >= 0x80 -> '?') with trailing
    /// NULs trimmed (embedded NULs kept); desc and unit the same way over their 64 and 32 bytes;
    /// a later duplicate name replaces the earlier entry.
    pub fn parse_live(map: &[u8], header: &SdkHeader) -> Result<VarTable, IbtError>;
    pub fn len(&self) -> usize;
    pub fn iter(&self) -> impl Iterator<Item = &VarHeader>;
    pub fn get(&self, name: &str) -> Option<&VarHeader>;

    // Readers over one sample row (`row.len() >= buf_len`). All return None when the variable
    // is absent, its type is not accepted, or the row is too short; never because of the value.
    /// Any type; char as unsigned byte, bool 0/1, int, bitfield as u32, float, double -> f64
    /// (C# ReadNumber). A non-finite float or double is returned as is (Some(NaN)).
    pub fn f64(&self, name: &str, row: &[u8]) -> Option<f64>;
    /// Int and bitfield read exactly (bitfield reinterpreted); bool/char as 0/1/byte;
    /// float/double truncated toward zero, None when non-finite or outside i32.
    pub fn i32(&self, name: &str, row: &[u8]) -> Option<i32>;
    /// Like i32 but i64; float/double rounded half to even (C# ReadLong).
    pub fn i64(&self, name: &str, row: &[u8]) -> Option<i64>;
    /// Int or bitfield only (C# ReadUInt).
    pub fn u32(&self, name: &str, row: &[u8]) -> Option<u32>;
    /// Bool only (C# ReadBool).
    pub fn bool(&self, name: &str, row: &[u8]) -> Option<bool>;
    /// Int or bitfield arrays into `out` (cleared first); leaves `out` empty when not accepted.
    pub fn i32_array(&self, name: &str, row: &[u8], out: &mut Vec<i32>);
    /// Float arrays only; every element as stored, non-finite included, so indices stay car indices
    /// (C# ReadFloatArray).
    pub fn f32_array(&self, name: &str, row: &[u8], out: &mut Vec<f32>);
}
```

### 3.4 Recording summary (ingest metadata)

Field-for-field port of `ibt_reader._extract_summary` (ibt_reader.py:705-826) with one fix from P5: `driver_setup_modified` reads `DriverInfo.DriverSetupIsModified`, falling back to `DriverSetupModified` (`worker-interface.md` section 5 item 3). ### 3.5 Session info

The in-house YAML subset of `ibt_reader._parse_iracing_yaml_subset` (ibt_reader.py:400-517) and `_yaml_scalar` (:342-372); no general YAML. The same parser serves IBT files and the live map.

```rust
#[derive(Debug, Clone, PartialEq)]
pub enum YamlNode {
    Map(Vec<(String, YamlNode)>),   // document order; a repeated key keeps both entries, lookups take the last (Python dict)
    List(Vec<YamlNode>),
    Scalar(Scalar),
    Literal(YamlScalar),            // leaf of an evaluated quoted or flow literal (below)
    Null,                           // key with no value and no block, or "- " with no block; a list item
                                    // "- Key:" with neither is Map([(Key, Map([]))]) (Python item_map[key] = {})
}

#[derive(Debug, Clone, PartialEq)]
pub struct Scalar { pub raw: String }   // text after "key:" or "- ", trimmed, quotes kept

#[derive(Debug, Clone, PartialEq, serde::Serialize)]
#[serde(untagged)]
pub enum YamlScalar { Null, Bool(bool), Int(i64), Float(f64), Str(String) }

impl Scalar {
    /// _yaml_scalar: "", "~", null/Null/NULL -> Null; true/yes/on, false/no/off (any case) -> Bool;
    /// quoted or flow text (below) -> the literal's value; integer pattern -> Int (Str when outside
    /// i64); float pattern and finite -> Float; else Str(raw).
    pub fn typed(&self) -> YamlScalar;
    /// Published text: `raw` without one pair of matching surrounding quotes.
    pub fn text(&self) -> &str;
}

#[derive(Debug, Clone, PartialEq)]
pub struct SessionInfo { pub root: YamlNode }

    /// Errors: tabs in indentation, tags/anchors/aliases, unexpected indentation, unconsumed

    /// Dotted lookup with list indices, e.g. "WeekendInfo.WeekendOptions.IsFixedSetup".
    pub fn get(&self, path: &str) -> Option<&YamlNode>;
    pub fn weekend(&self) -> WeekendInfo;
    pub fn sessions(&self) -> Vec<SessionEntry>;
    /// The DriverInfo.Drivers[] entry whose CarIdx == DriverInfo.DriverCarIdx.

    pub fn driver_setup(&self) -> DriverSetup;
    /// None when there is no CarSetup map.
    pub fn car_setup(&self) -> Option<CarSetup>;

```

**Quoted and flow literals** (`_yaml_scalar` :349-358). A value that starts and ends with the same quote character, or starts with `[` or `{` and ends with `]` or `}`, is evaluated as Python `ast.literal_eval` would, over this subset: string literals (single or double quotes, adjacent concatenation, Python escapes), integers, floats (`inf` on overflow), `True`, `False`, `None`, unary minus on numbers, and lists, tuples and dicts of these, nested. A result that is a list or tuple is stored as `YamlNode::List`, a dict as `YamlNode::Map` (string keys only, insertion order, a repeated key keeping its first position and last value), their leaves as `YamlNode::Literal`; a result that is a single string, number, bool or None stays a `Scalar`, whose `typed()` returns that value. When `literal_eval` would fail, `typed()` gives `Str` of the text between the quotes (quoted) or `Str(raw)` (flow). Any other result (set, bytes, complex, a non-string dict key) is `IbtError::Yaml` "unsupported flow literal": Python's later handling of those is not reproducible (set order depends on string hashing). Also `IbtError::Yaml`: a `\N{...}` escape or a lone surrogate in a string literal, a quoted key that evaluates to something other than a string, and an unhashable dict key or set element (Python raises `TypeError` there). An integer outside i64 inside a literal becomes `Str` of its decimal text, as a plain scalar does. So `WeekendOptions: {'IsFixedSetup': False}` reads as a map and `is_fixed_setup` is `Some(false)`, as in Python. A `Literal` leaf's published text (for `CarSetup.values`) is Python `str()` of the value. W1's golden test lists every quoted or flow value in the corpus.

### 3.6 Setup fingerprint

```rust
/// setup-keys.json: drop keys whose last segment matches an EXCLUDED_LEAF_PATTERNS entry
/// (case-insensitive, `_` in the segment ignored); for the rest in ascending UTF-8 byte order hash
/// key + 0x1F + value.trim() + 0x1E with SHA-256; lowercase hex, first 32 characters. Patterns use
/// only the subset stated in setup-keys.json (one group, optional with `?`), matched by a
/// hand-written matcher with ASCII case folding; a unit test over EXCLUDED_LEAF_PATTERNS fails on
/// any pattern outside the subset.
pub fn setup_values_fingerprint(values: &std::collections::BTreeMap<String, String>) -> String;
pub fn is_identity_excluded(key: &str) -> bool;
```

These two functions are the only Rust implementation of the `setup-keys.json` rules: the server or collector code that needs the rules (fingerprints, excluded-key lists, tolerance matching) calls them and never compiles the patterns with a regular-expression engine of their own, whose Unicode case folding would match keys the subset matcher does not (the Kelvin sign is not `k`). The browser may use `RegExp(pattern, "i")` without the `u` flag: that mode never folds a non-ASCII character to an ASCII one, so over these ASCII patterns it agrees with the subset matcher on `CarSetup` keys. On the snake_case keys of a garage `.htm` export it agrees only after removing `_` from the segment; a setup's `SetupDetail.identity_excluded_keys` carries the server's answer for either kind.

**Session epoch** (C# `LiveTelemetryService.ObserveSessionBoundary`): `session_epoch` (u32, starts at 0, wraps) increments, and the engine state resets, when the previous call was disconnected, `captured_unix_ms` went backwards, the engine lap decreased, or `session_unique_id`, `session.subsession_id`, `session_num` or the normalised session phase (`qual*` -> qualifying, `race`, `practice`, `warmup`, else the lowercase alphanumerics) changed between two known values. A disconnected sample after a connected one resets state without changing the epoch; the next connected sample starts a new epoch. (C# also increments at the disconnect, so its epoch numbers run ahead of these; boundaries fall in the same places, and disconnected frames carry no channels.)

Text rules (C# .NET formatting under the invariant culture; the TS twin follows them exactly, and `crates/coach-live/src/format.rs` with `tests/vectors/engine.json` is the reference):

| Rule | Output |
|---|---|
| number at precision n (`F{n}`) | the exact binary value rounded to n decimals, ties to even |
| `fixed2` cue argument (`0.00`); fuel's "{x.x} estimated laps" (`0.0`) | rounded half away from zero after reducing the value to 15 significant digits; always that many decimals ("0.70", "1.00") |
| steering ratio in the steering tile's secondary text (`0.##`) | the same rounding; trailing zeros and a trailing point dropped ("12:1", "14.5:1") |
| `percent0` | en-US `P0`: the exact value x 100 rounded ties to even, thousands separators, `%` appended (1,567%) |
| `ceil` | `Math.Ceiling` of the argument |
| `int` | a whole number carried as f32: the nearest integer, no decimals |
| lap time (`laptime`, `laptime-range`) | ticks truncated, fraction truncated to milliseconds; `m:ss.fff` from 60 s, `s.fff` below; hours dropped |
| signed delta | sign from the rounded text: a value that rounds to zero uses the zero section (no sign) |

### 4.8 Not in this crate

SDK map access, torn-read guard, staleness timer, frame decimation to 60 Hz, send queues, trend history buffers, garage capture state machine (all collector); relay and backlog (server).

Epoch marker (W3): `first_of_epoch` marks an engine state, but the collector sends only some states. It keeps a pending marker from the first state of each epoch and sets `first_of_epoch` on the first state of that epoch it actually encodes, including the first frame of a stream; a frame of a later epoch replaces the pending marker. Receivers still detect a boundary by a change of `session_epoch`, because frames may be dropped in the send queue or by the server's per-browser decimation (`live-frame.md`).

## 5. `coach_views` (W5)

Reads one `analysis.json` (streaming, only the needed subtrees) and writes the bounded view files the server serves. Accepted input: the worker's persisted document, flat (`analysis_id`, `schema_version` 2 and the analysis_view keys at the top level), or the analyze-result form `{analysis_id, analysis_view}` whose `analysis_view.schema_version` is 1; `race_investigation.schema_version` must be 2. Anything else is `IncompatibleVersion`. Copies backend values; the only rules it applies are the C# mapping rules named in `api.openapi.yaml` descriptions (tuning identity and map, lap exclusion reasons, representative runs, each run's `observed_trend`). Non-finite numbers and legacy `Infinity`/`NaN` tokens become null.

```rust
pub const PROJECTION_VERSION: u32 = 5;

/// Writes every view file into `out_dir` (`/data/views/<analysis_id>/p<PROJECTION_VERSION>/`),
/// which must not exist: files go to a sibling `<out_dir>.tmp-<random>` that is fsynced and
/// renamed; on error the temp directory is removed and nothing is left at `out_dir`.
pub fn project(analysis_json: &std::path::Path, out_dir: &std::path::Path) -> Result<ProjectionSummary, ProjectError>;

#[derive(Debug, Clone, PartialEq, serde::Serialize)]
pub struct ProjectionSummary {
    pub analysis_id: String,           // analysis.json analysis_id
    pub projection_version: u32,
    pub schema_version: i64,           // analysis_view schema the views carry: always 1 (ViewEnvelope.schema_version)
    pub profile_version: String,       // analysis_profile_version; "" when the backend left it null
    pub lap_count: u32,                // laps[] length
    pub bins_per_lap: u32,             // traces.ccol distance bins: lap_trace_columns (640) when the analysis has them, else lap_traces (160)
    pub trace_channels: Vec<String>,   // TraceSignal ids in catalog order
    pub files: Vec<ViewFile>,          // files actually written
    pub nonfinite_nulled: u64,         // numbers replaced by null
    pub elapsed_ms: u64,
}

#[derive(Debug, Clone, PartialEq, serde::Serialize)]
pub struct ViewFile { pub kind: ViewKind, pub file_name: String, pub bytes: u64, pub sha256: String }

#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize)]
#[serde(rename_all = "snake_case")]
pub enum ViewKind { Race, Runs, Investigation, TraceCatalog, Traces, Track, Tuning }
```

| ViewKind | File | Schema (`api.openapi.yaml`) | Bound | Absent when |
|---|---|---|---|---|
| Race | `race.json` | `RaceView` | 2 MiB | never |
| Runs | `runs.json` | `RunsView` | 1 MiB | never |
| Investigation | `investigation.json` | `InvestigationView` | 4 MiB | backend has no `race_investigation` (server answers 404 `not_found`) |
| TraceCatalog | `traces-catalog.json` | `TraceCatalog` | 512 KiB | never |
| Traces | `traces.ccol` | CCOL, all laps and channels | none (selection bound below) | never |
| Track | `track.json` | `TrackGeometry` | 512 KiB | `track_geometry` has no usable main path (404; the browser uses the distance strip) |
| Tuning | `tuning.json` | `TuningContextProjection` | 1 MiB | never |

When a JSON view would exceed its bound, the `x-source` subtrees whose `x-consumed-fields` is empty are emptied first: set to null where the schema allows null, else to `{}` (for example `TrackGeometry.provenance`, a required non-null object), so the shrunk view still validates against its schema. If it still exceeds, fields outside the consumed lists are removed from the remaining `x-source` objects (`api.openapi.yaml` info.description allows it). If it still exceeds, `project` fails with `TooLarge` (a defect to fix, never served).

Projector-written fields beside the backend's (version 2): `RaceView.pit_stops[]` lists each run's `pit_service` as a `PitStop` (the run's `end_lap`, the service window, the tires the backend observed changed, fuel added in litres and in gallons as litres over 3.785411784 rounded to 3 decimals, null where the backend reports nothing); `TraceLap.sector_times_s[]` gives each lap's seconds per sector, the session time at a sector's end fraction minus its start fraction, each linearly interpolated between the two `session-time` bins that straddle it (the desktop app's `TimeAtPercent`), the last sector ending at fraction 1, 3 decimals, null where the lap's bins stop more than two bins short of a boundary or the time is missing or negative, and present only when the catalog has at least two `sector_start_pcts`. Both are derived from backend values, not recomputed telemetry. Version 3 adds `InvestigationView.section_laps` (`SectionLaps`): per detected section, the section time of every lap the backend's screen kept (`race_investigation.laps[].eligible`) by the backend's own `race_inspection.section_elapsed`, ported line for line and checked against vectors that function produced (`crates/coach-views/tests/data/section-elapsed-vectors.json`), rounded to 3 decimals as Python rounds; the median, and the three fastest and three slowest with their difference to it.

The trace catalog serves at most 128 signals (`TraceCatalog.signals` maxItems): the fixed signals first, then the backend's additional signals in their order; the source keys beyond the cap are listed in `omitted_signals` and are not in `traces.ccol`. A real 82-lap recording gives 76 (wave 1).

```rust
/// Serves GET /api/v1/analyses/{id}/traces: reads `traces.ccol` and `traces-catalog.json` from

pub fn select_traces(view_dir: &std::path::Path, laps: Option<&str>, channels: Option<&str>, max_bytes: u64) -> Result<Vec<u8>, SelectError>;

#[derive(Debug, thiserror::Error)]
pub enum ProjectError {
    #[error("I/O: {0}")]
    Io(#[from] std::io::Error),
    #[error("malformed analysis.json at {path}: {message}")]
    Json { path: String, message: String },
    #[error("missing required field {0}")]
    MissingField(String),
    #[error("{field} {found} is not supported (supported: {supported})")]
    IncompatibleVersion { field: &'static str, found: String, supported: String },
    #[error("{kind:?} view is {bytes} bytes, bound {limit}")]
    TooLarge { kind: ViewKind, bytes: u64, limit: u64 },
    #[error("{0} already exists")]

pub enum SelectError {
    #[error("I/O: {0}")]
    Io(#[from] std::io::Error),

    BadLaps(String),                 // server: 400 invalid_request
    #[error("unknown channel {0}")]
    UnknownChannel(String),          // 400 invalid_request

}
```
