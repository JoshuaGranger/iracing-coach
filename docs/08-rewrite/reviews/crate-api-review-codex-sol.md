Transcribing the declared dependencies and types will not compile; `coach_wire`’s transitive dependency does not make `serde` available. **Smallest fix:** add `serde` with its derive feature to `coach_ibt`; specify the serialization dependency for `coach_live`’s golden types too.

2. **Major — [api.openapi.yaml, TuningOpenTarget](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/api.openapi.yaml:1778): unknown identities can compare equal.** “Same track_configuration_key” does not require either key to be present. Eligibility separately permits a layout without a configuration key, so two eligible records with null keys could match despite different tracks. `CompatibleOpenTarget` explicitly rejects missing/blank configuration keys and requires known car IDs or known car paths. **Smallest fix:** state those presence requirements and the exact comparison/fallback order.

3. **Major — [api.openapi.yaml, Lap/TraceLap](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/api.openapi.yaml:1418): comparison eligibility has no defined projected representation.** C# joins traces to laps and supplies `ComparisonEligible` and `ExclusionReason`, incorporating restart, traffic, off-track and damage exclusions. The contract provides an undocumented nullable `clean` and no exclusion-result field. W8 cannot reliably reproduce clean selection or explain exclusions from trace metadata. **Smallest fix:** define `clean`’s mapping—or add explicit eligibility—and add protected exclusion reasons, including the unmatched-lap behavior and W5’s join rule.

4. **Major — [crate-api.md §5](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/crate-api.md:809) / OpenAPI TrackGeometry: shrinking can produce invalid output.** The projector must null subtrees with empty `x-consumed-fields`; geometry `provenance` has an empty list but is a required, non-nullable object. Shrinking an oversized track view can therefore satisfy the byte bound while violating its schema. **Smallest fix:** retain `{}` for this object and restrict nulling to nullable fields.

5. **Major — [crate-api.md §§1, 3.2, 4.2](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/crate-api.md:152): array-element missing values are unrepresentable.** The global rule makes non-finite SDK floats missing, but `f32_array` and `Sample` use `Vec<f32>`. C# preserves array indices and raw NaNs, rejecting invalid gaps afterward. Removing invalid elements shifts car indices; replacing them with zero invents scoring data; emptying the array discards valid cars. **Smallest fix:** explicitly preserve non-finite elements in raw indexed arrays and normalize only derived results.

6. **Major — [crate-api.md §3.5](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/crate-api.md:257): YAML flow collections deliberately change Python semantics.** Python `_yaml_scalar` returns lists/maps for valid flow literals; the contract returns `Str(raw)`. For example, `WeekendOptions: {'IsFixedSetup': False}` becomes a map in Python but loses its setup classification under the proposed API. Absence from the current corpus does not establish parity for supported input. **Smallest fix:** represent successfully parsed flow collections as recursive `YamlNode` lists/maps.

7. **Major — [crate-api.md §3.4](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/crate-api.md:245): UTC strings cannot represent Python’s null result.** `_safe_iso` returns `None` when a timestamp is outside datetime’s range. A valid recording start plus a finite, enormous SDK end offset can produce a numeric end timestamp whose `end_time_utc` is null. The required Rust `String` forces rejection or invented text. **Smallest fix:** use `Option<String>` for the UTC fields and retain `_safe_iso`’s failure behavior.

8. **Major — [crate-api.md §4.6](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/crate-api.md:678): unknown present channels cannot be skipped.** `DecodedFrame` promises channels beyond the local table decode as `None`, but the frame carries neither their types nor their widths. If such a channel is present, the decoder cannot locate the cue block. Header validation nevertheless accepts this count when the table version is not newer. **Smallest fix:** reject counts exceeding the declared table’s channel count with a defined error; continue accepting shorter tables.

9. **Major — [crate-api.md §§4.5–4.8](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/crate-api.md:609): epoch marking has conflicting ownership.** `first_of_epoch` marks the first engine **state**, whereas `live-frame.md` marks the first transmitted **frame**. Collector-owned decimation can discard that state, leaving no transmitted frame marked as the boundary. **Smallest fix:** assign W3 responsibility for retaining the marker until the first frame of that epoch is emitted, and define stream-start behavior.

11. **Major — [crate-api.md §4.7, TileText](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/crate-api.md:743): dynamic display ranges are missing.** C# metric readings carry `Minimum` and `Maximum`; the fuel bar’s maximum is fuel amount divided by recorded fuel fraction, in the selected display unit. `TileText` exposes neither bound, and the static fuel tile has no maximum. 13. **Major — [crate-api.md §§1, 3.3, edge_scalar](/C:/Users/joshu/source/repos/iRacing%20Coach/docs/08-rewrite/contracts/crate-api.md:198): non-finite edge values can select stale identity.** Python `_read_edge_scalar` returns a last-record NaN; `_as_int` subsequently makes the identity unknown.
