# Rewrite workstreams

Each workstream owns its paths exclusively; it reads others' contracts, never their code. Cross-workstream needs are met by contract changes (`contracts/README.md`). Shared lock files (`Cargo.lock`, `pnpm-lock.yaml`): any workstream may change them; on a merge conflict take `main`'s version and re-run `cargo check` / `pnpm install`. After step 0, the scaffold's files (root manifests, `tools/check.ps1`, `tools/wire/`, `tools/theme/`, `tools/wsl/`, CI) change only through the contract change process; the existing `tools/*.py` and `tools/*.ps1` other than `tools/check.ps1` belong to W6. Explicit exceptions owned by W9: the root `.dockerignore`, deletion of `companion-app/` (wave 4), and removal of the .NET CI job, which W9 makes as a scaffold change through the contract change process.
