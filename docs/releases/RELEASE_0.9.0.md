# iRacing Coach 0.9.0

Version 0.9.0 replaces the 0.8.0 shell with usable local race-analysis and live-telemetry workspaces.

## Highlights

- Deep race review with strict evidence-aware grades, selectable lap overlays, telemetry-derived track display, synchronized traces, corner coaching, run context, tire-stress proxy, strategy, repairs, and compact Race Card.
- Live driving map, controls, metrics, trends, race gaps, configurable history, system-tray integration, and always-on-top Live Monitor.
- Local-history race briefing with fuel and pit calculations, tire/trigger guidance, corner phases, and comparable recorded runs.
- Read-only decoded setup library and comparison, plus structured progressive-tuning feedback and controlled-change workflow.
- Charcoal desktop theme with restrained telemetry colors, themed title bar and application icon, human-focused language, unobtrusive service activity, portable settings/data, and protected per-PC credentials.
