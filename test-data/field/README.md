# Synthetic opponent SDK recording

`synthetic-opponents.sdkfix` is a sanitized fake SDK memory-map replay. The three
`synthetic-opponents-*.field.jsonl` files are generated by the collector's real SDK
decoder and field segment writer, with one sample per simulated second. Each
segment covers 59 seconds; live capture is capped at 10 Hz.

Pair these files with `../ibt/synthetic-race.ibt`: player UserID 1,
SubSessionID 8001, SessionNum 1. The synthetic rival is CarIdx 1, UserID 2.
Its completed-lap counter advances at session times 50, 100 and 160 seconds.
Its pit-road boolean is true at times 110 through 119; lap distance pauses during
that visit. The first two completed laps are 50 seconds, the third is 60 seconds.
There is no final results snapshot or opponent fuel/tire-service evidence.

Regenerate explicitly from the repository root:

```powershell
cargo test -p coach-collector --lib emit_sanitized_field_fixture -- --ignored
```

Normal tests do not regenerate the corpus. This synthetic replay establishes
format and pipeline behavior, not real rig performance or private race evidence.
